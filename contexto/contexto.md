Projeto integrador — aplicação web com Firestore e API
Projeto individual: desenvolva uma aplicação web funcional, conectada a um banco de dados na nuvem e a uma API externa.

Nesta atividade, você desenvolverá um sistema a partir de um tema escolhido por você. O projeto deverá combinar operações de cadastro com dados obtidos de uma API pública e ser publicado na nuvem.

Requisitos obrigatórios do sistema
1 · CRUD completo
Firebase / Firestore
O sistema não pode ser apenas uma tela estática de consulta. Deve permitir:

C — Cadastrar: formulário para inserir novos registros.

R — Consultar: listagem dos dados salvos no Firestore.

U — Atualizar: opção para editar registros existentes.

D — Excluir: opção para remover registros do banco.

2 · API externa
Dados públicos e gratuitos
O sistema deverá consumir dados de uma API pública e gratuita, relacionada ao tema escolhido, e exibir essas informações na interface da aplicação.

3 · Publicação
Vercel
A aplicação final deverá estar publicada e acessível pela internet, com endereço terminado em .vercel.app.
